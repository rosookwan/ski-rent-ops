# 장비 대여·가격·견적 설계안

상태: 2026-09-07 신규 요청에 대한 설계 권고. 실제 매장 요금 정책은 설정값 확정 후 적용합니다.

## 권고 방향

카운터에서 고객과 상품을 선택하면 요금·할인·견적이 계산되고, 대여 확정 시 같은 기록에서 배달·수거 업무가 만들어지는 구조를 권고합니다. 장부, 견적서, 차량 보드에 각각 같은 내용을 다시 입력하지 않게 합니다.

가격은 ‘정가 → 사용할 단골·제휴 요금 선택 → 추가 할인’ 순서로 계산하고, 계산에 사용한 당시 값과 사유를 거래에 보관합니다. 관리자 가격표를 수정해도 확정된 과거 견적·대여 금액이 바뀌지 않아야 합니다.

## 상품과 수량

| 상품 | 기본 분류 | 관리할 정보 |
|---|---|---|
| 스키 | 대여 장비 | 등급·사이즈 등 선택 옵션, 대여 단위, 기간별 요금 |
| 보드 | 대여 장비 | 등급·사이즈 등 선택 옵션, 대여 단위, 기간별 요금 |
| 의류 | 대여 장비 | 상하의 세트인지 낱개인지 표시, 사이즈, 기간별 요금 |
| 바이저헬멧 | 대여 장비 | 일반 헬멧과 구별되는 상품·요금 |
| 헬멧 | 대여 장비 | 사이즈, 기간별 요금 |
| 고글 | 대여 장비 | 등급, 기간별 요금 |
| 보호대 | 대여 장비 | 세트 구성·수량 단위, 기간별 요금 |
| 리프트권 | 이용권 판매 | 스키장·이용일·권종·대상 구분·수량·판매가. 필요하면 공급가 |

스키 1대에 부츠·폴이 포함되는지, 의류·보호대의 1개가 무엇인지 관리자 화면에서 표시합니다. 상품 수량의 단위는 견적서와 기사님 준비·수거 목록에 동일하게 나타나야 합니다.

리프트권의 오후·야간·후야는 각각 등록 가능한 권종입니다. ‘후야’를 자동으로 오후권과 야간권 두 장으로 나누지 않습니다. 권종의 실제 이용시간·성인/소인·주중/주말·특정일 조건은 해당 스키장과 매장 판매 규칙에 맞게 설정합니다.

물리적 회수 대상 여부를 상품에 둡니다. 대여 장비는 수거·반납 대상이지만, 리프트권 판매를 장비 미반납 수량에 포함하지 않습니다.

## 카운터 화면

기본 흐름은 ‘고객 선택 → 상품 수량 → 이용일·수령·반납 방법 → 가격·할인 확인 → 견적 또는 대여 확정’입니다.

간단 모드는 상품 버튼, 큰 수량 조절, 1일·2일·3일 버튼, 단골 5,000원·10,000원 할인, 합계, 견적서·대여 확정 버튼을 우선 보여줍니다. 가격 수정은 해당 상품 줄을 눌러 열고, 기본 화면에 모든 세부 설정을 펼치지 않습니다.

자세한 모드에서는 상품별 이용 기간, 권종·날짜별 리프트권, 할인 사유, 결제 나누기, 견적 이력 등을 확인합니다. 고객 이름·연락처만 같은 경우 기존 고객과 자동 합치지 않고 검색 결과에서 선택하게 합니다. 과거 가격은 참고 자료이며 이번 요금으로 자동 확정하지 않습니다.

가족·단체가 같은 기간에 빌리면 상품을 수량으로 묶습니다. 기간·요금·반납 일정이 다르면 같은 상품이라도 줄을 나눕니다. 예: 스키 2대는 3일, 스키 1대는 1일.

## 고객 찾기와 장비 이용 내역

‘고객 찾기’에서 대표자 이름 또는 연락처 일부를 입력해 검색합니다. 전화번호는 하이픈·공백을 제외하고 비교합니다. 동명이인이나 같은 연락처의 여러 기록은 이름·전화번호·메모를 보고 직원이 선택하며 자동으로 합치지 않습니다.

고객 상세에는 대표자 이름, 연락처, 메모와 대여·예약 내역을 표시합니다. 각 내역에서 이용 날짜, 일수, 장비별 실제 수량, 당시 최종 금액을 확인합니다. ‘이 고객으로 접수’는 고객 정보만 채우며 과거 장비·할인·가격을 새 접수에 자동 적용하지 않습니다. 신규 등록과 정보 수정은 별도 버튼으로 제공합니다.

확정 내역은 고객 ID로 연결하고 당시 이름·연락처·장비·가격도 별도 보존합니다. 고객 정보를 수정해도 과거 거래의 당사자 정보를 소급 변경하지 않습니다. 매장 간 고객 검색·자동 병합은 허용하지 않습니다.

## 오늘 수령과 미래 이용일 구분

신규 접수의 이용 시작일·종료일은 매장 시간대의 오늘로 시작합니다. 날짜 선택기로 미래 날짜를 지정할 수 있고, 1·2·3일 버튼은 선택한 시작일을 유지하면서 종료일을 변경합니다. 시작일을 바꾸면 현재 일수를 유지하며 종료일을 이동합니다. 종료일을 직접 바꾸면 두 날짜를 포함한 기본 일수를 계산합니다. 종료일이 시작일보다 빠르거나 날짜가 비어 있으면 저장을 막고 안내합니다.

예를 들어 12/19에 장비를 미리 수령하고 12/20~21에 이용하면 청구 이용일은 2일이며, 오후타임 후 반납은 12/21, 익일 오전 반납은 12/22입니다. 수령일·실제 장비 점유 기간과 요금 이용 기간은 따로 기록합니다. 사전 수령 요금과 재고 배정은 매장 정책으로 정하며 이용 시작일까지 장비가 매장에 있는 것으로 처리하지 않습니다.

첫 시안은 오늘의 매장 수령 접수를 가정하고 이용 날짜를 편집합니다. 별도 수령 예정일·배달 일시 선택과 재고 점유 처리는 후속 구현입니다. 야간 이용일 경계·기간별 요금표는 아래 정책 설계에 따르며 시안의 달력 일수 계산이 모든 매장의 영구 정책은 아닙니다.

## 다일 대여를 읽기 쉽게 입력하는 방법

사용자가 추가 설명한 의미는 ‘장비 1개를 이틀 빌리면 물품은 1개이고 요금만 이틀분’입니다. 금액을 맞추기 위해 상품 수량을 2로 입력하게 하지 않습니다.

화면 위에서 모든 대여 장비에 공통으로 적용할 **이용 기간**을 한 번 선택합니다.

`이용 기간  [1일] [2일 선택] [3일] [직접 입력]`

그 아래에서 날짜별 이용 수량을 입력합니다. 1일 단가와 계산식은 프로그램이 표시합니다. 아래는 같은 장비를 같은 수량으로 이틀 내내 쓰는 경우의 가상 금액 예시입니다.

| 상품 | 실제 수량 입력 | 적용 기간 | 1일 단가 | 계산 내역·금액 |
|---|---|---|---:|---:|
| 스키 | [−] **1대** [+] | 2일 | 20,000원 | 1대 × 2일 = **40,000원** |
| 의류 | [−] **1개** [+] | 2일 | 10,000원 | 1개 × 2일 = **20,000원** |
| 총액 | | | | **60,000원** |

요약에는 ‘대여 물품: 스키 1대·의류 1개 / 이용 기간: 2일’을 표시합니다. 견적서에도 수량 1과 이용일수 2를 별도 열로 출력합니다. 준비표·차량 보드·반납 확인에는 실제 물품 수량인 스키 1대·의류 1개를 전달합니다.

같은 수량을 계속 이용하는 경우 위 계산을 유지합니다. 날짜별로 수량이 다르면 **장비 / 리프트권 탭 → 날짜 선택 → 그날 사용할 수량** 순서로 입력합니다. ‘이 수량을 모든 이용일에 적용’은 선택한 날의 수량을 다른 이용일에도 복사하며, 이후 특정 날짜만 다시 수정할 수 있습니다. 특정 상품만 이용하지 않는 날은 0개로 둡니다.

| 이용 날짜 | 스키 이용 수량 | 1일 단가 | 할인 전 요금 |
|---|---:|---:|---:|
| 첫날 | 4개 | 20,000원 | 80,000원 |
| 둘째 날 | 3개 | 20,000원 | 60,000원 |
| 합계 | 날짜별 수량 합산 | | 140,000원 |

이때 7개는 실제 지급·수거 수량이 아닙니다. 시안에서는 상품별 일 최대 수량(이 예에서는 4개)을 지급·수거 수량의 제안값으로 표시합니다. 날짜별 수량이 다른 접수는 직원이 **실제 지급 수량과 마지막 수거 예정 수량을 확인한 뒤 저장**합니다. 서로 다른 장비를 나누어 지급했다면 지급 수량을 늘릴 수 있습니다. 지급 4개 중 1개를 이미 별도로 돌려받았다면 마지막 수거를 3개로 입력할 수 있습니다. 일별 합계나 마지막 날 이용 수량으로 수거 수량을 자동 확정하지 않습니다.

지급 수량은 일 최대 수량 이상·일별 수량 합계 이하의 정수, 마지막 수거는 0부터 실제 지급 수량까지의 정수로 확인합니다. 장비의 날짜별 수량이 바뀌면 제안값으로 다시 계산해 재확인합니다. 단순 시작일 이동은 일차별 수량과 확인한 실제 수량을 유지하고, 기간을 늘리면 새 날짜에 마지막 날 수량을 복사합니다. 기간을 줄이면 범위 밖 장비 입력을 제외합니다. 선택한 리프트권의 사용 날짜는 장비 기간 변경으로 이동하지 않습니다.

중간 배달·중간 수거 일정의 생성, 이미 반납한 수량의 증빙과 누적 잔량 관리는 후속 구현입니다. 현재 시안의 마지막 수거 수량 확인은 반납 이력 기록을 대신하지 않습니다. 실제 서비스는 지급·수거 이력으로 잔량을 계산하고 모든 물품이 확인되어야 주문 전체를 반납 완료로 처리해야 합니다.

이용 날짜와 반납 예정을 따로 표시합니다. 반납은 ‘오후타임 후 / 야간타임 후 / 익일 오전 / 직접 시간 선택’으로 받고, 선택 결과의 실제 날짜·시간을 함께 보여줍니다. 이용일수를 바꾸면 작성 중인 타임 선택의 날짜를 마지막 이용일 기준으로 다시 계산합니다. 직접 지정한 날짜와 이미 저장·배정된 업무는 조용히 변경하지 않습니다. 기존 건의 일정 변경은 저장 전에 확인합니다.

리프트권은 공통 장비 일수로 곱하지 않습니다. 별도 ‘리프트권’ 탭에서 날짜별 권종과 매수를 선택합니다.

## 가격 관리자

| 설정 | 내용 |
|---|---|
| 상품 관리 | 표시 이름·사진·카테고리·수량 단위·사용 여부·정렬 순서·회수 대상 |
| 기본 요금 | 1일 요금 또는 이용권 1매 가격, 적용 시작·종료일 |
| 날짜 조건 | 매장이 사용하는 주중·주말·특정일·시즌별 요금 |
| 다일 방식 | 기본은 일수 비례. 필요하면 2일·3일 등 기간별 총액표 선택 |
| 단골·제휴 | 요금표 이름, 업체, 적용 상품, 상품별 단가 또는 정액 할인 |
| 추가 할인 | 상품별 허용 여부, 직원별 할인·가격 수정 범위 |
| 리프트권 | 스키장, 권종, 날짜 조건, 대상 구분, 판매가·선택 공급가 |
| 계산 정책 | 원 단위 절사·반올림, 추가 할인 중복 허용 여부 |

관리자는 변경 가격을 1일·2일·3일 예시로 미리 확인한 뒤 적용합니다. 적용 중인 요금표의 버전을 보관하고, 이미 확정된 대여 건은 당시 가격을 유지합니다. 새 가격을 기존 건에 적용하려면 해당 건에서 명시적으로 재견적해야 합니다.

가격이 등록되지 않은 상품은 ‘요금 미등록’으로 표시합니다. 누락된 가격을 0원으로 간주하지 않습니다. 의도적인 무료 제공은 별도 0원 서비스 처리와 사유로 기록합니다.

## 장비당 할인과 총 금액 할인

1차 접수 화면은 퍼센트를 사용하지 않고 **장비당 할인 / 총 금액 할인** 두 가지 정액 할인만 제공합니다. 기본 버튼은 **단골 5,000원 / 단골 10,000원**입니다. 이름·금액을 바꾸는 기능은 추후 관리자 화면으로 옮기며, 현재 접수 화면에서는 할인 항목을 새로 등록하지 않습니다.

| 구분 | 적용 단위 | 예시 |
|---|---|---|
| 장비당 할인 | 해당 상품의 실제 장비 1개당, 대여 기간 전체에 한 번 | 스키 2대에 장비당 5,000원 → 총 10,000원 할인 |
| 총 금액 할인 | 장비당 할인 후 남은 장비 금액에 적용 | 5,000원 두 번 + 10,000원 한 번 → 총 20,000원 할인 |

장비당 할인은 실제 수량만 곱하고 대여 일수를 다시 곱하지 않습니다. 스키 2대를 이틀 빌려도 장비당 5,000원 할인 합계는 10,000원입니다. 각 장비 줄에서 지정 금액과 해당 줄의 할인 결과를 보여줍니다. 장비당 금액은 5,000원 또는 10,000원 중 하나를 선택하고 ‘장비당 할인 해제’로 제거합니다.

메인 화면의 총 금액 할인 버튼은 **누를 때마다 누적**합니다. 같은 5,000원 버튼을 두 번 눌러도 두 번 적용하며, 서로 다른 금액도 합산합니다. ‘5,000원 × 2번 + 10,000원 × 1번’처럼 적용 횟수를 항상 표시합니다. ‘한 번 취소’는 마지막 총 할인 클릭 한 건을 되돌리고, ‘전체 해제’는 총 금액 할인만 지웁니다. 이미 지정한 장비당 할인은 별도로 유지합니다.

### 계산과 한도

1. 날짜별로 상품 단가 × 그날의 이용 수량을 계산해 장비 기준액을 합산합니다. 매일 같은 수량이면 기존 단가 × 수량 × 일수와 같습니다. 리프트권은 날짜·권종·매수별로 별도 합산합니다.
2. 장비당 정액 × 확인한 실제 지급 수량을 차감합니다. 시안은 같은 상품의 요금 합계를 한도로 적용하며 일별 수량 합계나 최종 수거 수량을 할인 수량으로 사용하지 않습니다. 개별 장비별 기간·할인 배분은 후속 설계 범위입니다.
3. 누적한 총 금액 할인을 남은 할인 대상 장비 금액에서 차감합니다.
4. 장비당 할인 합계, 실제 총 금액 할인 적용액, 두 할인의 합계, 최종 금액을 구분해 보여줍니다.

리프트권은 첫 설정에서 두 할인 모두 제외합니다. 총 금액 할인 입력 합계가 남은 대상 금액을 넘으면 실제 적용액은 남은 금액까지만 제한하며 입력액과 적용액의 차이를 표시합니다. 최종 금액이 0원 아래로 내려가지 않습니다. 한도까지 할인한 상태에서는 더하는 버튼을 비활성화하되 취소·해제는 가능합니다.

실제 서비스에서는 장비당 할인액과 총 할인 클릭 목록(항목 ID·당시 이름·당시 금액·순서), 최종 적용액·배분 결과·사유·담당자·시각을 거래에 보관합니다. 관리자가 기본 금액을 바꿔도 저장된 접수의 적용값을 소급 변경하지 않습니다. 상품별 원 단위 배분·정정 이력은 서버 구현 범위이며 첫 시안은 합계와 입력 흐름을 검증합니다.

## 2일·3일 대여 판단

**기본 권고는 ‘실제 청구할 이용일수에 따른 계산’입니다.** 2일은 1일 요금의 2배, 3일은 3배로 시작하고, 장기 할인은 매장이 설정한 기간 요금이나 할인으로 명확히 표시합니다.

사용자의 후속 설명으로 ‘1개를 이틀 빌리면 수량은 1개, 요금은 2일분’이라는 의미를 확인했습니다. 이 원칙을 이용일수 전체에 적용해 3일은 3일분으로 계산하는 설계를 권고합니다. 별도 장기 할인은 매장이 설정할 때만 적용합니다.

1일 요금과 매일 이용하는 장비 수량이 모두 동일한 경우:

`장비 기본금액 = 1일 요금 × 실제 장비 수량 × 청구 이용일수`

예시 가격은 실제 매장 요금이 아닙니다.

| 스키 1대, 1일 20,000원 | 기본 계산 | 2일·3일 총액을 따로 설정한 예 |
|---|---:|---:|
| 1일 | 20,000원 | 20,000원 |
| 2일 | 40,000원 | 36,000원 |
| 3일 | 60,000원 | 50,000원 |

기간별 총액 36,000원·50,000원은 해당 기간 전체에 대한 장비 1개의 가격입니다. 여기에 이용일수를 다시 곱하지 않습니다. 설정하지 않았다면 기본 일수 계산을 적용합니다. 매장에서 2일과 3일을 모두 40,000원으로 받는 정책이라면 두 기간의 총액을 같은 값으로 설정할 수 있습니다.

날짜별 요금이 다르면 날짜별 금액을 합산합니다. 예: 첫날 20,000원, 다음 날 25,000원이라면 2일 금액은 45,000원입니다. 기간별 총액표는 어떤 날짜·시즌 조합에 적용되는지 범위를 정합니다. 혼합 기간에 적용할 총액 규칙이 없으면 날짜별 합산을 사용하며 계산 내역에 표시합니다.

실제 렌탈 서비스에도 일 단가 방식과 기간별 총액 방식이 별도로 있습니다. 이 프로젝트는 매장 설명과 현장 입력을 단순하게 유지하기 위해 일수 계산을 기본안으로 선택했습니다. [가격 방식 참고](https://help.booqable.com/en/articles/84968-the-different-ways-of-pricing-products)

## 이용일수와 반납 시각의 관계

다음 세 가지는 따로 저장합니다.

| 정보 | 목적 |
|---|---|
| 이용 날짜·청구 일수 | 요금 계산 |
| 실제 장비 보유 기간 | 대여 가능 수량과 장비 점유 확인 |
| 배달·수거·반납 예정 | 현장 표현, 선택 방식, 실제 예정 날짜·기준 시간을 저장하여 차량·카운터 업무 정렬 |

자정이 지났다는 이유만으로 일수를 자동 증가시키지 않습니다. 밤 8시부터 다음 날 새벽 0시 30분까지의 야간 이용은 매장 규칙에 따라 한 이용일일 수 있습니다. 반대로 오늘 오전부터 내일 오후까지 사용하면 두 이용일로 계산할 수 있습니다. 화면은 시작·종료 일시에서 일수를 제안하되, 적용 이용 날짜와 금액을 카운터가 확인할 수 있어야 합니다.

프로그램의 ‘1일’을 무조건 24시간이나 달력 날짜 차이로 고정하지 않습니다. 첫 매장의 야간 이용일 경계와 요금 규칙을 설정한 뒤 자동 계산을 켭니다. 하루 마감의 영업일 경계와 청구 이용일 규칙도 각각 설정합니다.

스키 2대를 3일 빌렸다면 요금 계산에는 6대·일을 사용하지만 실제 배달·재고·반납 수량은 2대입니다. 카운터와 기사님 화면에 6대로 전달하지 않습니다.

예를 들어 스키 1대·의류 1개를 12/20~21 이틀 이용하고 ‘익일 오전’을 고르면 반납은 12/22 오전입니다. 기본 예시 요금은 60,000원, 실제 수량은 각각 1개로 유지합니다. 요금은 확인한 청구 일수로 계산하고, 장비는 실제로 돌아올 때까지 점유 상태입니다. 익일 오전 선택이 무료 연장을 확정하는 것은 아니며, 허용 반납 시간과 추가 요금 여부는 매장 정책으로 따로 결정합니다.

기간 연장은 기존 금액에 단순히 1일 정가를 더하는 방식으로 고정하지 않습니다. 연장 후 기간 총액을 계산하고 기존 확정액과의 차액을 조정 내역으로 남깁니다. 원래 요금표 버전을 기본으로 사용하고 다른 요금을 적용하면 표시합니다. 조기 반납도 물건을 받은 사실과 요금 환급 정책을 분리하며 자동 환불하지 않습니다.

## 리프트권은 날짜·권종별 계산

장비를 3일 빌려도 리프트권은 첫날 후야, 둘째 날 오후, 셋째 날 미구매일 수 있습니다. 따라서 장비 일수에 리프트권 금액까지 일괄 곱하지 않습니다.

리프트권은 ‘이용일 + 권종 + 대상 구분 + 수량’을 한 줄로 기록하고 각 줄의 가격을 합산합니다. 동일한 권종을 여러 날짜에 복사할 수는 있지만 실제 선택한 날짜별 줄이 남아야 합니다.

### 권종이 많을 때의 입력 방식

상품 선택 영역 맨 위에 **장비 / 리프트권** 탭을 둡니다. 리프트권 탭에서는 장비 카드 대신 리프트권만 고릅니다. 글자·버튼 크기를 유지하며, 이용 기간은 한 줄로 요약하고 ‘변경’에서 펼칩니다.

1. **날짜 선택:** 첫날·둘째 날 버튼에 날짜와 선택 매수를 표시합니다. 첫날 4매, 둘째 날 3매처럼 독립적으로 수정하며 합계는 7매입니다. 별도 사용 날짜도 달력에서 선택할 수 있습니다.
2. **권종 선택:** 기본은 자주 쓰는 오후·야간·후야 성인권입니다. 소인·성인 전체, 권종 이름 검색, 전체·타임권·시간권 분류를 제공합니다. 샘플 16종은 한 페이지에 최대 6종씩 표시합니다. 이름 검색을 시작하면 전체 권종에서 찾습니다.
3. **선택 내역:** 오른쪽 견적에는 선택한 날짜·권종·대상·매수·금액만 표시합니다. 해당 줄을 누르면 리프트권 탭의 그 날짜·권종으로 이동합니다. 0매는 그 날짜의 해당 줄만 제거합니다.
4. **같은 수량 복사:** ‘이 수량을 모든 이용일에 적용’은 선택한 날짜의 권종·매수를 이용 기간의 각 날짜에 복사하며 해당 날짜들의 기존 선택을 교체합니다. 복사 후에도 날짜별로 수정할 수 있습니다. 이용 기간 밖의 리프트권은 유지합니다.

선택은 별도 팝업의 적용 버튼 없이 현재 접수 초안과 견적에 바로 반영됩니다. 실제 접수 저장은 메인 ‘접수 저장’ 버튼으로 합니다. 탭·날짜를 이동해도 입력한 다른 날짜의 수량은 유지합니다.

같은 날짜·권종·대상의 추가는 한 줄의 매수를 늘리고 다른 날짜는 별도 줄로 남깁니다. 장비 이용일을 변경해도 이미 선택한 리프트권 날짜를 자동 이동하지 않습니다. 실제 서비스에서 날짜를 바꾸는 편집은 해당 날짜의 판매 가능 여부와 요금을 다시 확인한 새 줄로 처리하며, 기존 거래의 단가를 소급 변경하지 않습니다. 리프트권만 구매한 접수도 가능하고 차량 수거 업무를 만들지 않습니다.

시안의 오전·오후·야간·후야·종일·3/4/6시간권과 성인·소인별 가격은 입력 흐름 검토용입니다. 관리자 화면에서 매장별 권종, 요금, 판매 날짜, 자주 쓰는 버튼과 순서를 설정하는 기능은 후속 구현입니다. 실제 시간·요일 요금 판정이나 공급사 발권까지 구현한 것은 아닙니다.

리프트 요금의 이용시간·요일 조건은 스키장별로 다릅니다. 이 문서에서는 사용자에게 제시된 오후·야간·후야를 설정 가능한 이름으로 취급하고 실제 운영시간·가격을 고정하지 않습니다. [공식 요금 구조 참고](https://www.jisanresort.co.kr/w/ski/use/rental.asp)

## 가상 계산 예시

3일 이용, 스키 2대·의류 2개와 이틀치 리프트권을 구매하는 사례입니다. 아래 금액·할인은 검산용입니다.

| 항목 | 정가 기준 | 선택 요금표 적용 후 |
|---|---:|---:|
| 스키 2대 × 3일 | 20,000 × 2 × 3 = 120,000원 | 제휴 단가 16,000 × 2 × 3 = 96,000원 |
| 의류 2개 × 3일 | 10,000 × 2 × 3 = 60,000원 | 제휴 단가 8,000 × 2 × 3 = 48,000원 |
| 첫날 후야권 2매 | 60,000 × 2 = 120,000원 | 120,000원 |
| 둘째 날 오후권 2매 | 45,000 × 2 = 90,000원 | 90,000원 |
| 합계 | 390,000원 | 354,000원 |
| 장비 대상 전체 추가 할인 | — | −4,000원 |
| 최종 대여·이용권 금액 | — | **350,000원** |

정가 대비 차이는 제휴 요금 적용 36,000원과 추가 할인 4,000원으로 나눠 보관합니다. 4,000원 추가 할인은 스키 2,667원·의류 1,333원에 배분하여 스키 최종 93,333원, 의류 최종 46,667원으로 기록합니다. 리프트권 합계는 210,000원입니다.

## 견적서와 대여 확정

‘견적서’ 버튼에서 화면 미리보기, A4 인쇄, PDF 저장을 제공합니다. 견적서에는 매장명·연락처, 견적번호·버전·작성일·유효기간, 고객·제휴업체, 이용 기간, 상품·수량·요금 기준, 할인, 최종 금액, 배달·수거·반납 일정과 메모를 담습니다. 출력 시 세금 포함 여부는 매장이 설정한 표시 정책을 사용합니다.

견적 저장·출력만으로 매출, 수납, 확정 배달 업무가 발생하지 않습니다. ‘대여 확정’을 눌렀을 때 대여 기록과 필요한 배달·수거 업무가 만들어집니다. 견적 내용은 그대로 넘기고 동일 견적을 반복 클릭해 중복 대여 건이 만들어지지 않게 합니다.

가격 변경 후 재견적하면 새 버전을 생성합니다. 고객에게 이미 제시한 이전 견적과 비교할 수 있어야 합니다. 확정 대여 건을 수정할 때도 변경 내역·사유를 남깁니다.

받은 예약금·결제액은 최종 금액 아래에 따로 표시하고 미수금을 계산합니다. 돌려줄 보증금은 대여 할인이나 매출로 포함하지 않습니다. 마감 계산은 [하루 마감 설계안](03-daily-closing.md)을 따릅니다.
