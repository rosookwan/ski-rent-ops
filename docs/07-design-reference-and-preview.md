## 첫 시안

- 소스: [first-look.fragment.html](../design/prototypes/first-look.fragment.html)
- 매장 접수: 상품 수량, 1·2·3일 선택, 리프트권, 추가 할인, 고객·반납 정보, 견적 미리보기.
- 이용일: 매장 시간대(시안은 한국)의 오늘을 기본으로 시작일·종료일 선택. 미래 이용을 미리 접수하며 기간 버튼·요금·반납 타임을 함께 갱신.
- 고객: 대표자 이름·연락처 일부로 검색, 동명이인 선택, 고객 등록·정보 수정, 장비별 실제 수량·기간·금액의 이용 내역. 접수를 저장하면 선택한 고객의 이력에 반영.
- 할인: 장비당 정액 할인과 메인 총 금액 할인. 기본 단골 5,000원·10,000원 버튼이며 메인에서는 클릭마다 누적. 적용 횟수, 한 번 취소·전체 해제, 할인 합계를 표시. 장비당 할인은 실제 수량만 곱하고 일수는 곱하지 않음. 리프트권은 제외.
- 반납 예정: 오후타임 후·야간타임 후·익일 오전·직접 날짜/시간. 매장 수거·직접 반납 모두에 적용하며 저장한 일정과 견적에 표현·날짜·시각을 함께 표시.
- 타임 기준 설정: 세 타임의 시각을 시안 안에서 편집. 기존 접수의 시각은 보존하고 작성 중인 건은 저장할 때 변경 반영. 실제 서비스의 매장별 설정 버전·시즌 관리·권한은 아직 미구현.
- 상품 선택: 맨 위의 장비 / 리프트권 탭에서 각각 선택. 첫날·둘째 날 버튼에 날짜와 수량 표시, 장비와 리프트권 모두 날짜별 다른 수량 입력. ‘이 수량을 모든 이용일에 적용’으로 복사 후 개별 수정.
- 리프트권: 별도 팝업 없이 탭에서 바로 수정, 16종 샘플 검색·대상·분류·6종씩 페이지 이동. 날짜별 매수·금액과 전체 선택 내역 표시. 메인 견적의 줄을 누르면 그 날짜·권종으로 이동.
- 장비: 날짜별 단가 × 이용 수량을 합산. 실제 지급·마지막 수거 수량을 별도로 표시하고 수정 가능. 일별 수량이 다르면 일 최대 수량을 제안하고 저장 전에 실제 수량 확인. 차량에는 확인한 마지막 수거 수량만 전달.
- 장비 기간을 바꿔도 선택한 리프트권 날짜는 유지. 리프트권만 판매하면 견적·고객 이력에 남기고 차량 수거 업무는 생성하지 않음. 실제 발권·날짜별 판매 가능 여부·주중/주말 요금 판정·권종 관리자 설정은 후속 구현.
- 일정 보드: 매장 직접 반납과 차량 배달·수거를 함께 보여줍니다.
- 차량: 날짜·종류·시간 또는 장소 정렬, 간단·자세한 모드, 우선 확인 요청과 기사님 확인, 연락처·문자 화면.
- 완료 흐름: 차량 수거 완료 → 매장 확인 대기 → 매장 최종 확인 후 반납 완료.
- 다일 접수의 수거는 실제 반납일에 표시하며 오늘 업무에 섞이지 않습니다.
- 매장과 차량 탭은 같은 시안 안의 샘플 상태를 공유합니다. 별도 기기 간 실시간 동기화가 구현됐다는 뜻은 아닙니다.

가상 매장명, 이름, 연락처, 가격을 사용합니다. 신규 접수·샘플 차량 업무는 시안을 연 날의 한국 날짜를 기준으로 생성하며, 이용 날짜를 바꿔 미래 일정을 확인할 수 있습니다. 타임 시각 16:30·22:00·09:00은 설정 예시이며 실제 리프트 운영시간으로 확인한 값이 아닙니다. 고객 등록·수정, 할인 적용, 접수 저장·타임 설정·문자 발송은 시안 내부 상태 변경이며 새로 열면 초기화됩니다. 전화 연결·실제 문자·알림 소리·화면 꺼짐 방지·결제·인쇄·서버 저장은 연결하지 않았습니다. 결과 형식은 인터랙티브 화면이며, 새 `.fig` 파일을 생성한 것은 아닙니다.

이번 접수 화면은 오늘의 매장 수령을 기본으로 합니다. 배달은 기존 샘플 건에서 동작을 보여줍니다. 새 접수의 수령일·배달 정보 입력, 부분 수거·반납, 직접 반납 완료 처리, 요금표 관리자·제휴 정산, 하루 마감은 이후 화면 작업 범위입니다. 기본 할인 이름·금액 변경은 추후 관리자 화면 범위이며 접수 화면에서 등록·퍼센트 기능은 제공하지 않습니다. 간편 할인 버튼은 별도 단골·제휴 요금표와는 구분합니다. 한 개의 접수 초안을 수정·저장하는 시안이며, 여러 새 주문을 계속 생성하는 실제 POS까지 구현하지 않았습니다.

## 디자인 기준

매장과 차량은 서로 다른 Figma 자료를 기준으로 배치와 스타일을 구분합니다.

| 대상 | 참고 파일 | 적용한 구성 |
|---|---|---|
| 매장 POS 모니터 | Makaryo Point Of Sales Free | 밝은 회색·흰 패널·주황 포인트, 상품/고객·반납/견적의 3개 작업 영역. 모니터에서는 나란히, 좁은 화면에서는 세로 재배치 |
| 차량 갤럭시 탭 | Task management & to-do list app | 보라색·연보라 배경, 둥근 업무 카드, 날짜·업무 선택, 큰 장소·반납 타임과 연락·완료 버튼. 간단/자세한 모드 |

Wanted는 한글 가독성과 구성 요소 참고로 사용합니다. 서로 다른 디자인이어도 배달은 파랑, 수거는 주황, 완료는 초록의 상태 의미를 유지하고 글자를 함께 씁니다. 참고 파일을 그대로 변환한 결과가 아니라 스키샵 업무와 각 기기에 맞춰 다시 구성한 시안입니다. Task management 원본의 휴대폰 화면을 그대로 늘린 것이 아닙니다.

반납은 현장 문구와 날짜를 먼저 보여주고 기준 시간을 보조로 표시합니다. ‘익일 오전’은 마지막 이용일의 다음 날로 표시하며 대여 일수와 요금은 자동 증가하지 않습니다. 실제 거치 거리와 조명에서의 검증은 남아 있습니다.

매장 화면은 글자와 터치 버튼 크기를 그대로 유지하고 날짜·고객 정보·견적의 상하 여백만 소폭 줄였습니다. 장비와 리프트권은 탭으로 나누며 리프트권 탭의 공통 기간은 한 줄로 요약하고 필요할 때 펼칩니다. 날짜가 하나뿐이면 날짜 선택 버튼은 생략합니다. 선택한 항목이 늘면 자연스럽게 세로로 이어지며 차량용 주요 버튼 크기는 유지합니다.

현재 시안의 실제 지급·마지막 수거 수량은 계획값입니다. 중간 배달·수거 업무나 이미 반납한 장비의 증빙·잔량을 자동 기록하지 않습니다. 최종 수거 업무의 완료가 주문 전체 물품의 반납을 증명하는 것으로 확장하지 않습니다.

주행 중에는 필요한 정보와 알림을 확인하고, 전화·문자·완료 버튼은 정차 후 사용하는 흐름을 전제로 합니다. 시안의 큰 화면 배치는 갤럭시 탭 자체에서 시험한 결과가 아닌 브라우저 크기별 검토입니다.

## 이번 시안에서 확인한 동작

2026-09-07 브라우저에서 날짜별 수량 입력 시안을 확인했습니다. 아래 금액은 모두 샘플 가격입니다.

- 기존 동일 수량: 스키 1개·의류 1개를 이틀 사용하면 60,000원.
- 날짜별 장비: 스키 첫날 4개·둘째 날 3개, 단가 20,000원 → 140,000원. 날짜·탭을 이동해도 각 날 수량 유지.
- 날짜별 리프트: 오후권 성인 첫날 4매·둘째 날 3매, 단가 45,000원 → 315,000원. 장비와 합쳐 455,000원.
- 실제 지급 4개에 장비당 5,000원은 한 번씩 총 20,000원 할인. 총 할인 5,000원 두 번 + 10,000원 한 번까지 적용하면 최종 415,000원.
- 일별 수량이 다른 접수 저장 시 실제 수량 확인. 지급 4개·마지막 수거 3개로 확인하면 기사님에게는 스키 3개만 표시. 지급보다 많은 수거 수량 입력은 차단.
- 고객 이력에는 실제 지급 4개와 첫날 4개·둘째 날 3개의 이용 내역을 구분하며 날짜별 금액은 할인 전으로 표시. 견적에도 날짜별 장비·리프트권과 실제 지급·수거 수량 표시.
- 장비·리프트권의 선택 날짜 수량을 모든 이용일에 복사하고 특정 날만 수정 가능. 리프트권 0매로 제거 시 해당 날짜의 줄만 제거.
- 4개·3개인 이틀 장비를 3일로 늘리면 4개·3개·3개. 선택한 리프트권의 날짜·매수는 유지.
- 장비 시작일을 비우면 안내와 저장 차단, 화면 실행 유지. 리프트 사용 날짜를 비우면 매수 추가 차단.
- 탭에서 4시간권 검색 + 소인 필터, 견적의 리프트권 줄에서 해당 날짜로 이동 확인.
- 장비 없이 날짜별 소인 4시간권 1매씩 구매하면 70,000원. 접수·견적에 두 날짜를 표시하고 차량 수거 업무는 생성하지 않음.
- 1366px에서 두 탭의 매장 배치를 확인. 736px·360px에서 장비와 리프트권 탭, 360px 실제 수량 확인창의 가로 넘침 없음.
- 차량 1024×800의 간단·자세한 모드와 72px 주요 버튼 유지. 자바스크립트 구문 검사, 브라우저 실행 오류, 문서 상대 링크 및 시안 복사본 일치 확인.

이 검증은 화면과 샘플 계산에 대한 확인입니다. 실제 갤럭시 탭·차량 환경, 서버 동기화, 실제 발권·문자·결제·반납 잔량 검증은 포함하지 않습니다.
