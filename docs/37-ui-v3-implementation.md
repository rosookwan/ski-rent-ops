## 2. 공통 셸 (모든 POS 화면)

- **좌측 레일 96px 고정**: 아이콘 24px + 14px 글자, 항목 56px. 포스 9개(오늘 할 일 · 1 접수·예약 · 2 준비·지급 · 3 이용·변경 · 4 반납·회수 · 5 정산·마감 · 리프트권 · 차량 운행 · 관리). 관리는 맨 아래 고정, 누르면 레일이 관리 메뉴(포스로 · 재고·정비 · 거래처 장부 · 고객 관리 · 매장 설정 · 인쇄물 · 마감 이력)로 바뀐다. 접힘/펼침 없음.
- **상단 56px**: 매장명(매장 설정 > 매장 정보) · 화면 제목 · 처리 대기 칩 · 요약 숫자 최대 3개 · 알림 · 연결 상태 · 나가기. 1280px 미만은 요약 2개, 1100px 미만은 요약을 숨긴다.
- **필터 줄 56px**: 검색 · 오늘/내일/전체 칩(건수 표시) · 달력 · 정렬(시간 묶음/접수 순서). 글자만 있는 필터 줄은 아예 그리지 않아 빈 줄이 생기지 않는다.
- **본문**: 시간대(수령/반납 타임)별로 묶은 카드 격자 `minmax(360px,1fr)` (1366에서 3열, 1024에서 2열). 카드 영역 하나만 스크롤하고 상단·필터·하단은 고정.
- **하단 72px**: 왼쪽 요약 문장, 오른쪽 보조 버튼 + 주 버튼 56px 주황.
- **카드 규격**: 이름·연락처·상태 배지 / 접수번호·이용일·수령(반납) 시간·장소 / 품목 줄(품목 수량 + 상태) / 금액 줄(미수 빨강, 보증금 파랑) / 버튼 1개. 빨강·주황·초록 상태는 2px 테두리 + 테두리 위 상태 글자, 완료 카드는 초록 빗금.
- **색·아이콘**: 핸드오프 토큰(#fe4e10 계열, 회색 단계, 상태색 5종) 그대로, 아이콘은 번들된 Lucide.
- **차량 단말(기사 로그인)**: 레일 없음, 보라 팔레트(#5F33E1), 주 버튼 72px, 업무 카드에 전화 버튼. 화면 구성은 공급받은 기존 화면 유지.

## 4. 문구

- 상태는 명사형으로 통일: 지급 전 · 이용 중 · 일부만 받음 · 차량 보관 중 · 반납 완료 · 교환 대기 · 확인 필요, 품목 줄은 지급 전/대여 중/차량 수거 예정/차량 보관/반납 완료/발권 예정.
- 돈은 미수 · 수납 · 지급 · 환불 · 보증금, 매장 설정은 사용/미사용 계열의 표준 용어, 시간대는 `09:00~12:00 수령`처럼 숫자로 표기.
- 확정 버튼 문구(`모두 반납 확정`, `선택 물품 지급 확정`, `확인하고 저장` 등)는 검증 스크립트가 누르는 문구라 그대로 두었다.

## 6. 남은 확인 사항

- 1024×600에서 오늘 할 일 9장은 두 줄이 넘어 카드 영역을 넘겨 본다(상단 `지금 처리` 줄이 가장 급한 팀을 바로 연다). 매장에서 600 높이 단말을 실제로 쓸지에 따라 3열 카드를 더 낮출지 결정.
- 차량 단말은 아직 같은 번들에서 기사 로그인으로 분리되어 있다(별도 앱 분리는 이후 작업).
- 예전 `rental-board` · `vehicle-board` · `dispatch-board` 모듈은 번들에 남아 있으나 pos-* 등록이 덮어써서 화면에는 나오지 않는다. 정리는 별도.
- 실물 단말에서 글자 크기·터치 크기(48/56/72px)를 눈으로 한 번 확인할 것.

## 9. 차량 화면은 행 목록으로 유지 (2026-09-17)

기사 태블릿은 브라우저 주소창을 빼면 1024×520 정도라 카드 목록이 한 번에 2건밖에 보이지 않았다. 사용자 결정에 따라 **기사 로그인 화면은 카드 예외**로 두고 이전 행 목록으로 되돌렸다. 매장 POS의 `차량 운행` 보드는 카드 그대로다.

- `차량 운행`(기사): 행 목록 페이지. 한 행에 `시간 · 팀 · 배달/수거`, 아래 줄에 `장소 · 남은 물품 N개 · 품목`, 오른쪽에 보라색 56px `업무 처리`. 화면 높이 520 → 3행, 600 → 4행, 720 → 5행, 그 이상 6행. 필터 줄은 오늘·이전/내일/전체/달력만 두고 검색은 뺐다. 하단 요약에 담당 차량을 표시한다.
- `차량 보관`(기사): 품목별 행 목록.
- `배달·수거 처리`: 변경 없음(−/+ 수량, 72px 확정 버튼, 전화).
- 촬영·검사: `npm run pos:screens:driver`(새 스크립트 `scripts/capture-pos-driver.cjs`)가 실제 API 서버에 기사로 로그인해 1024×520 / 1024×600 / 1280×720에서 5장을 찍고 넘침·본문 스크롤·레일 숨김·행 수를 검사한다 → `docs/pos-ui-v3/driver-*.png`, `driver-screens.json`. 최소 버튼 48px.
- 재검증: `npm run check`, operating 12 · fulfillment 16 통과.
