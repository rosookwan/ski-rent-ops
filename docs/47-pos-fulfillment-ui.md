# 47. 지급·반납 A1 화면 정리

2026-09-21. `docs/46` A1. P20·P22 시안과 기존 화면을 비교한 뒤 사용자 확인("하나씩 진행", "임의로 폰트 변경이나 줄바꿈 … 최대한 없게", "UI샘플에 최대한 맞춘다")을 받고 구현했다.

## 변경 사항

- 준비·지급, 일부 반납, 모두 반납, 차량 물품 입고를 기존 목록·접수 상세 위의 확인 창에서 처리한다. 제목은 `대표자 · 지급/반납 확인/매장 입고 N개`다.
- 품목은 이름·보조 설명과 공용 `.pos-stepper`의 − / 수량 / +를 한 줄에 둔다. Pretendard와 기존 공용 크기(본문 16/18px, 제목 24px, 수량 26px)를 유지했다. 새 글꼴, 글자 축소, 강제 줄바꿈을 넣지 않았다.
- 미수는 회색 띠와 기존 빨간색으로 표시한다. `수납`에서 기존 금액 확인 절차로 들어가며, 완료·취소 후 고른 수량으로 돌아온다. 돈과 물품은 각각 기존 명령으로 저장한다.
- `모두 반납 확정`에서 수량을 줄이면 `받은 수량 반납 확정`으로 바뀐다. 남은 실물은 고객 보유로 남는다.
- 품목이 많으면 높이에 맞춰 쪽을 나눈다. 500개 판매행에서도 앞뒤 쪽 이동과 창 크기 변경 때 수량을 보존한다. 오래된 자료로 확정하면 저장하지 않고 오류와 `최신 수량으로 다시 선택`을 보여 준다.
- `규격·준비`, `발권 기록`, `선택 초기화`, `전량`, 기존 확정 문구와 동작 이름을 유지했다. 규격 준비를 취소해도 지급 창으로 돌아온다.

## 시안과의 대응

| 시안 | 실제 화면·코드 | 유지한 차이와 이유 |
|---|---|---|
| P20 지급 창 | `pos-fulfillment-view.js`의 `show`·`row`, `pos-fulfillment.js`의 `open`·`confirm` | `규격·준비`·`발권 기록` 입구를 남겼다. 실제 규격·발권 사실을 확인하는 기존 업무 기능이다. |
| P22 반납 확인 창 | 같은 품목 행·미수 띠·하단 버튼. 일부 반납과 차량 입고도 공용 배치 | 확정 문구는 `docs/42` 부록 A를 유지한다. 차량 입고의 보조 설명에는 실제 보관 차량을 보인다. |
| 시안의 고정 3행 | 기본 예시 3행, 많은 품목은 높이별 쪽 나눔 | 1024×600에서 창 한도 552px, 버튼 52px, 글자 16px 이상을 지킨다. |
| 시안에는 없는 보조 수량 설정 | `수량 설정` → 초기화·최신 수량·품목별 수량 상세 | 품목별 `전량`과 긴 상세 설명은 기존 화면에서 계속 쓸 수 있다. 일상적인 지급·반납은 확인 창에서 마친다. |
