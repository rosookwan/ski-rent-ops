## 2. 카드 규격 (40·41·42·43·44·45·47·48·52 공통, 첨부 1)

핸드오프 행의 5열(이름 / 수량 / 상세 2줄 / 금액 / 버튼)을 카드 5줄로 옮긴다.

| 줄 | 내용 | 글자 |
|---|---|---|
| 그룹 헤더 | `오후타임 후 16:30 반납 · 3팀`. 41·42는 수령 시간대, 43·44는 반납 시간대, 45는 전달 시간, 47·48은 `고객 / 거래처`, 52는 `이용 중 / 예약 / 지난 이용` | 20px/700 + 16px #6d6d6d |
| 1 | 대표자 이름 · 연락처 · 상태 배지(우측 끝) | 20px/700 · 16px · 배지 14px/600 |
| 2 | 접수번호 · 이용일 · 수령/반납 시각 · 장소 | 15px #6d6d6d |
| 3 | **품목 줄, 품목마다 1줄**: 좌 `스키 3세트`, 우 상태 `지급 전 / 지급 완료 / 대여 중 / 차량 수거 예정 / 차량 보관 / 반납 완료(취소선) / 미반납` | 18px/700 · 우 15px/600 상태색 |
| 4 | `미수 115,000원`(빨강) · `보증금 30,000원`(파랑). 없으면 줄 생략 | 17px/700 |
| 5 | 주 버튼 1개, 우측, min-height 48px, 라벨은 4절 교체 후의 행 버튼 라벨. 완료 상태는 회색 비활성 `완료` | 16px/700 |

- 열: 1366px 이상 3열, 1024~1365px 2열. gap 12px, 카드 padding 16px, radius 14px, 테두리 `inset 0 0 0 1px #e7e7e7`, 배경 #fff.
- 카드 본문 탭 = 접수 상세. 버튼 = 그 단계 처리 팝업(핸드오프 팝업 그대로).
- 필터바 오른쪽 끝에 정렬 토글 `시간 묶음 / 접수 순서`.
- 핸드오프의 28px 수량 열과 상세 2줄은 품목 줄로 흡수. 합계는 헤더 요약이 담당.
- 상태 배지 색: 핸드오프 STATUS 표 그대로. 색만으로 표시하지 않는 규칙 유지.
- 40 오늘 할 일: 단계별 카드 7장(1366px 4열, 1024px 3열). 1줄 단계명 + 배지, 3줄 자리에 큰 숫자 28px + 상세 2줄, 버튼 `열기`.
- 1024×600 확인값: 헤더 56 + 필터 56 + 푸터 72 = 184px, 목록 416px에 카드 2단 보임.
