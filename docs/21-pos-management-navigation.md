# 포스·관리 메뉴 전환

작성일: 2026-09-08

포스에서는 현장 업무 메뉴만 표시하고, 왼쪽 맨 아래의 `관리화면으로` 버튼으로 관리 메뉴에 진입한다. 관리에서는 같은 위치의 `포스화면으로` 버튼으로 직전에 보던 포스 화면에 복귀한다. 접힌 메뉴에서도 `관리` 또는 `포스` 글자가 표시되며, 메뉴 목록만 스크롤하고 전환 버튼은 아래에 고정한다.

## 메뉴 구성

| 포스 | 관리 |
| --- | --- |
| 오늘 현황 | 오늘 현황 |
| 새 대여 접수 | 리프트권 예약 |
| 렌탈현황 | 거래처 장부 |
| 반납 확인 | 하루 마감 |
| 배달·수거 | 고객관리 |
| 리프트권 예약 | 재고·정비 |
| 사전 입력·준비 | 매장 설정 |
| | QR 이용 안내 |

## 화면과 데이터

- 관리 전환 버튼은 포스와 동일한 `오늘 현황` 대시보드를 연다. 별도의 관리 대시보드나 메뉴 선택 화면을 복제하지 않는다.
- 대시보드 본문, 업무 화면 배치, 입력 항목, 계산과 처리 기능은 유지한다.
- 대시보드의 거래처·마감 바로가기는 관리 메뉴로, 관리 대시보드의 접수·렌탈 업무 바로가기는 포스 메뉴로 이어진다.
- 리프트권 예약과 보관·환불 상세는 동일한 화면과 업무 원장을 사용하고, 진입한 쪽의 메뉴를 유지한다.
- 관리 방문 전 포스 화면의 상세 접수번호와 검색·선택 탭, 작성 중 접수 내용을 유지한다. 로그아웃하면 복귀 위치를 초기화한다.
- 메뉴 구분은 접근 권한 구분이 아니다. 별도의 관리자 비밀번호나 실제 인증을 추가하지 않았다.
- 데이터 유지 범위는 기존 체험과 같다. 같은 페이지 안에서만 이어지며 새로고침·다른 기기 사이의 영구 저장이나 공유 기능을 추가하지 않았다.

## 검증

- `npm run check`: JavaScript 36개, 인라인 스크립트 1개, 정적 빌드 통과.
- `npm test`: 기존 기능 72개 통과.
- `npm run test:navigation`: 공통 대시보드, 메뉴 이동, 접수 작성값·렌탈 상세 유지, 리프트권 예약 공유, 바로가기·로그아웃, 크기별 하단 전환 버튼의 6개 브라우저 시나리오 통과.
- `npm run test:intake`: 기존 접수 13개 브라우저 시나리오 통과.
- 메뉴 확인 크기: 1366×768, 1024×768, 1024×600, 390×740. 접힘·펼침 모두 확인했다.
- 좁은 화면에서 펼친 사이드바가 겹쳐 표시될 때 본문을 기존 두 번째 열에 유지해, 상단 메뉴 버튼과 알림 버튼이 겹치던 문제를 보완했다.

검증 결과와 화면은 로컬 `work/menu-split/`에 생성된다. 실제 매장 포스 하드웨어에서의 확인과 공개 배포는 별도다.
