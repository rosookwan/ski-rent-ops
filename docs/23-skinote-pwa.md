# 스키노트 브랜드와 PWA 화면 테스트

작성일: 2026-09-08

## 적용한 브랜드

| 항목 | 값 |
|---|---|
| 설치 이름 · 짧은 이름 | 스키노트 |
| 영문 | SKINOTE |
| 대표 문구 | 렌탈샵의 하루를 한눈에. |
| 설명 | 스키·보드 렌탈샵의 접수부터 대여, 배달·수거, 반납과 하루 마감까지 한곳에서 확인하는 운영 도구 |
| 로고 | 보라색 노트 안에 기울어진 흰색 스키 두 줄 |
| 브랜드 색 | `#6550ba` |

사용자가 선택한 도형의 비율과 색상을 유지했다. SVG 원본 `design/app/assets/app-mark.svg`에서 설치용 SVG·PNG를 만들며, maskable 아이콘은 원형 안전 영역 안에 로고 전체가 들어가도록 여백을 확보했다. Apple 터치 아이콘은 180px이다. PNG 재생성은 `npm run icons:build`로 실행한다.

설치 이름·브라우저 제목·로그인 브랜드는 스키노트다. 업무 화면에는 기존 매장 설정의 상호와 스키노트를 함께 표시한다. 포스 업무의 주황색과 차량 업무의 보라색, 메뉴 구성·위치·전환 동작은 유지했다.

## 작업 경계

별도 작업의 포스/관리 메뉴 분리와 기본 PWA 구현이 완료될 때까지 공통 소스를 수정하지 않았다. 완료 후 24개 변경 파일의 사본과 해시를 `work/skinote-brand/baseline/`에 보관하고 그 위에 적용했다.

이 변경의 주요 범위는 로고·manifest·문구, `app-mode.js`와 `app-host.js`, 설치 안내 스타일, 빌드 연결과 PWA 검사다. 메뉴 분리 검사를 다시 실행해 공통 대시보드, 접수 중 입력, 상세화면·필터와 리프트권 예약 유지가 계속 동작하는지 확인한다.

## 실행과 설치

[스키노트 체험 화면](https://rosookwan.github.io/ski-rent-ops/)을 일반 Chrome 또는 Edge에서 열고 로그인 화면의 설치 버튼 또는 브라우저 설치 메뉴를 사용한다. 설치 가능 이벤트가 아직 없으면 버튼은 안내를 표시한다. 이미 앱 창으로 실행 중이면 설치 버튼을 숨긴다.

아이폰·아이패드는 Safari에서 공유 → 홈 화면에 추가를 선택한다. 표시되는 경우 “웹 앱으로 열기”를 켠다. 설치 메뉴와 실행 시 사이트 주소를 잠시 표시하는 방식은 브라우저에 따라 다르다.

설치한 스키노트 아이콘을 열면 매장 POS / 차량 화면 선택이 나온다. `standalone` 모드에서 일반 탭과 주소창을 제외한 독립 창으로 실행된다. 운영체제의 상태표시줄·창 버튼은 남을 수 있다.

## 구현과 동작

- manifest와 설치 제어 코드는 최상위 문서에 둔다. 업무 iframe은 기존 `sandbox="allow-scripts"`와 저장·네트워크 제한을 유지한다.
- 아이콘과 시작 주소는 manifest 기준 상대 경로다. 루트 개발 주소와 `/ski-rent-ops/` 배포 주소 모두 검증한다. 기존 시작 주소에서 계산되는 앱 식별자를 유지한다.
- 일반 브라우저의 기존 화면 이동은 유지한다. 설치 앱에서만 최상위 브라우저 방문 기록과 내부 화면·포스/관리 모드를 연결한다.
- 방문 기록에는 임시 세션 식별자와 위치 번호만 기록한다. 고객명·연락처·대여 ID나 입력값을 URL/브라우저 방문 기록에 쓰지 않는다. 화면별 이동 정보는 현재 페이지 메모리에 둔다.
- 로그인·로그아웃은 현재 이동 상태를 교체한다. 로그아웃하거나 다시 실행한 뒤 이전 로그인 상태로 돌아가지 않는다.
- 최상위 페이지가 화면 안전 여백과 동적 높이를 처리하며, 지원 브라우저에서 키보드가 나타나면 내용 영역을 줄이도록 지정한다.

## 체험의 한계

이 버전은 온라인 화면 테스트용이다. 서비스 워커, 오프라인 업무 처리, 영구 저장, 다른 기기와 동기화, 실제 인증·문자·결제·백그라운드 푸시는 추가하지 않았다. 설치는 이 기능들을 활성화하지 않는다.

같은 페이지의 매장/차량 전환은 메모리를 공유하지만 별도 앱 창·탭·기기는 공유하지 않는다. 페이지가 유지된 채 앱을 잠시 전환했다 돌아오면 상태가 남을 수 있으나, 새로고침·완전 재실행 또는 운영체제의 페이지 회수 후에는 초기화된다. 화면이 숨겨지면 기존 알림 소리는 멈춘다.

## 검증

```sh
npm run check
npm test
npm run test:pwa
SKI_DEMO_URL=http://127.0.0.1:58162/ npm run test:navigation
```

`test:pwa`는 임시 Chrome 프로필에서 실제 설치와 독립 창 실행, 이름과 아이콘, 포스/관리 전환, 브라우저 뒤로/앞으로, 앱 내부 뒤로가기, 로그아웃·재실행을 확인한다. 검사한 앱과 임시 프로필만 정리한다. 테스트는 Chromium PWA 창이 실제 iframe을 그리도록 기본적으로 브라우저 창을 연다.

기존 기능 검사는 72개, 메뉴 전환 검사는 6개, 설치 PWA 검사는 6개 시나리오다. 설치 검사 기록은 `work/pwa/checks.json`, 크기별 화면 확인은 `work/skinote-pwa/`에 남긴다.

로컬 Chrome의 설치·독립 창은 실제 검증 대상이다. Windows/Edge, 갤럭시 탭과 iPhone/iPad의 홈 화면 설치, 실제 소프트 키보드·제스처와 인쇄 하드웨어는 해당 기기에서 확인해야 한다. 크기 변경으로 확인한 화면은 물리 기기 검증으로 간주하지 않는다.
