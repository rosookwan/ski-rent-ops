# 51. 시안과 달라진 부분의 사유와 현재 마무리 상태

2026-09-21. 사용자 요청: "지금까지 한거 마무리하고 업무상 필요로 인해 달라진 것들은 사유를 써줘 문서에".

## 현재 상태

- 화면 코드는 `feat/pos-ui-v4`의 `aa1dae6`까지다. A1~A4 구현과 업무 검사는 이 버전에 남아 있다. 추가로 시작한 A4 재수정은 미완성 상태라 걷어냈다.
- **A4는 업무 검사를 통과했지만 시안 일치는 미완료다.** 사용자가 재고·거래처 비교 그림의 차이를 지적했다. 기존의 "시안에 맞춤", "완료" 보고를 시각적 일치 확인으로 해석하면 안 된다.
- 추가 화면 수정과 A5 착수는 여기서 멈춘다. `main`·Pages·운영 서버에는 반영하지 않았다.
- 아래의 업무 사유는 **데이터와 처리 절차를 보존하는 이유**다. 버튼 모양·패널 비율·여백·색·배치를 임의로 바꿔도 된다는 뜻이 아니다.

## 기능·자료가 아직 없는 부분

이 항목들은 업무상 반드시 달라야 하는 디자인이 아니라 **시안 대비 남은 구현 범위**다.

| 화면 | 남은 차이 | 현재 사실 |
|---|---|---|
| M02 재고 | 시안의 `재고 목록 인쇄`가 없고 현재 하단에는 `실물 목록`이 있다. | 이번 A4에서는 재고 인쇄를 구현하지 않았다. 인쇄 대신 다른 버튼을 배치한 것을 시안 충족으로 볼 수 없다. |
| M04 거래처 | 담당자, 단가·일수에 따른 개별 대여 요금 표시 | 현재 거래처 저장은 이름·전화, 약정은 거래처 단위 금액·사유다. 예시 담당자나 단가를 실제 값처럼 넣지 않았다. 이 자료가 필요하면 별도 기능 구현이 필요하다. |
| M04 거래처 | `장부 인쇄`·`전화` 버튼이 현재 거래처 상세에 없다. | A4에서 해당 진입점을 연결하지 않았다. 특히 전화는 다른 접수 상세에 기존 `tel:` 연결이 있으므로, 시스템 전체가 전화를 지원하지 않는다는 사유는 맞지 않는다. |
| 고객 상세 | 고객 상세 전용 시안 | 인계 문서에는 P04 접수 상세의 좌우 배치를 사용하라고 되어 있다. 비교 그림의 P04를 고객 상세 전용 승인 시안으로 표현하지 않는다. |

## 업무 사유로 정당화할 수 없는 모양 차이

아래는 `aa1dae6`에 남아 있는 **시안 불일치**다. 공용 부품 재사용이나 자동 검사 통과는 변경 사유가 되지 않는다.

| 위치 | 시안 | 현재 구현·남은 일 |
|---|---|---|
| 공통 바깥 배치 | 헤더가 맨 위 전체 폭을 차지하고 레일은 그 아래에서 시작한다. | 레일이 화면 맨 위까지 올라와 헤더의 시작 위치가 다르다. |
| M02 상태 변경 | 타일 하단 전체 폭의 흰 테두리 버튼 | 작은 주황색 `상태 변경 ›`로 바뀌었다. 버튼 형태와 위치를 복원해야 한다. |
| M02 타일 | 한 줄 수량 설명, 진한 초록 알약 배지, 시안의 카드 높이·간격 | 두 줄 설명과 연한 배지, 다른 높이·모서리·여백을 사용했다. 데이터 차이와 분리해서 맞춰야 한다. |
| M04 왼쪽 정보 | 시안의 넓은 정보 패널과 여섯 버튼 | 1024px 화면에서 260px로 좁아지고 정보·버튼 구성이 달라졌다. |
| M04 상단 | 탭 오른쪽에 미수·미지급을 계속 표시 | 1100px 이하에서 합계를 숨긴다. 왼쪽에 같은 금액이 있어도 시안과는 다르다. |
| M04 오른쪽 | 품목 카드 바로 아래에 금액표 | 카드와 금액표 사이에 큰 빈 공간이 생겼다. 높이 배분을 다시 맞춰야 한다. |
| M04 하단 | 요약과 목록 버튼, 주황색 수납 버튼 | 요약이 빠지고 주 버튼이 물품 빌려주기/빌려오기로 바뀌었다. 돈·실물의 처리 구분은 유지하면서 시안의 주 동작을 복원해야 한다. |

## 검증 기록과 인계

`aa1dae6`에서 업무 검사 6종·단위 180·반납 25·알림 18·PWA 6·check·빌드가 통과했고, 화면 규칙 291곳에서 위반이 없었다. 이는 기능·잘림·크기·스크롤 검사 결과이며 **시안과 같다는 검사 결과가 아니다**. 상세 수치는 [docs/50](50-pos-management-details-ui.md)에 있다.

이번 마무리에서는 미완성 재수정을 제거한 뒤 화면 코드가 `aa1dae6`과 같고 문서 링크·변경 내용이 맞는 것을 확인했다. 앱 코드를 추가로 바꾸지 않아 전체 업무 검사를 다시 실행한 것으로 보고하지 않는다.

**할 일:** 다시 작업할 때 이 문서의 시안 불일치를 먼저 확인한다. A4 시안 일치와 A5는 남은 일이며 이번에는 착수하지 않는다.

**알고만 있을 것:** 현재 공개 체험판은 기존 `main` 버전이다. A1~A4 작업 브랜치의 화면과 다르다. 사용자 파일 `docs/25-label-printer-purchase-notes.md`는 변경·커밋하지 않았다.
