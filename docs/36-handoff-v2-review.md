**대부분 그대로 구현해도 된다.** 레일, 카드 목록, 문구, 42 준비·지급 통합, 41-1 추가 모드, 43·44·45·47·48·52·56·57은 요청서대로 나왔다.

## 2. 구현 시 보정 내용

① **관리 레일 교체**: `관리`를 누르면 레일이 `포스로 · 재고·정비 · 거래처 장부 · 고객 관리 · 매장 설정 · 인쇄물 · 마감 이력`로 바뀐다. 첫 화면 매장 설정. 요청서 35 §1.

② **54 접수 상세**: 필터바 자리 탭 줄 위 또는 좌측 요약 아래에 56px 버튼 4개 `일행·장비 추가(→ 41-1 추가 모드, 대표자 고정) · 수납·환불(= 결제 탭 팝업) · 문제 해결·정정(5선택: 못 받은 물품 · 시간·장소 변경 · 잘못 입력함 · 파손·분실 · 고객 미도착) · 전화(tel:)`. 탭은 6개를 4개로 줄여도 된다: `일행·사이즈 · 품목(장비 + 리프트권) · 수납·환불(결제) · 이력(변경 이력 + 메모)`.

③ **차량 운행**: 현재 배달·수거 보드(첨부 4: 싣기 · 방문 순서 ▲▼ · 수거·매장 인계)를 유지한다. 55에서 가져올 것 두 가지. 헤더 요약 `미배차 · 운행 중 · 완료`, 미배차 카드의 `배차하기` 팝업(차량 2칸 선택 + 남은 건수).

④ **46 차량 단말**: 현재 화면 유지. 가져올 것은 `일부만` 팝업의 품목별 −/수량/+ 와 부족 시 빨간 줄, 경고줄 `미수거분 목록 유지`, 문구 교체(일부만 받았어요 → 일부만 받음, 확인했어요 → 확인). 핸드오프 46의 `적재분 · 배달분 · 수거분 · 전달분 · 하차분 · 차량 보관분` 어휘는 현재 차량 화면 어휘와 섞이므로 쓰지 않는다.

⑤ **51 · 카드**: `매장 정보` 탭(상호 · 전화 · 주소 · 입력 링크) 추가, 헤더 `우리 스키샵`과 49·50이 이 값을 쓴다. `스키장 템플릿`·`새 접수 화면` 버튼 삭제. 카드 그리드 `minmax(360px,1fr)` → 1366 3열, 1024 2열.

## 4. 그대로 쓰는 수치
