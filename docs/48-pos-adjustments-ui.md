# 48. 기간·수거 변경·교환·문제 해결 A2 화면 정리

2026-09-21. `docs/46` A2. 사용자 요청("다음도 마저 진행")에 따라 P24·P25·P26 시안과 `docs/35`의 해당 업무를 대조하고 구현했다. 글꼴이나 줄바꿈을 임의로 바꾸지 않고 시안에 맞춘다는 기존 요청을 유지했다.

## 변경 사항

- 기간 연장은 종료일 선택 버튼과 공용 달력을 쓴다. 선택한 날짜에 따라 남은 물품의 추가 일수·금액을 다시 계산한다. `남은 1개만 연장`과 반납한 실물의 기간을 유지하는 동작은 그대로다. 금액·사유 직접 확인도 남겼다.
- 수거 약속은 날짜·장소·시간·차량을 한 줄씩 고른다. 매장에 등록한 장소·반납 타임·차량을 사용하며, 목록 밖 장소·시간은 직접 입력한다. 익일 타임을 다시 눌러도 날짜는 한 번만 이동한다.
- 교환은 실제 등록된 규격을 큰 버튼으로 고른다. 현재 실물·규격, 교환 품목, 사이즈 변경/파손 교체, 매장/차량 교환을 확인할 수 있다. `교환 내용 확인` 다음에 기존 요청 확인으로 이어지고 새 장비 지급과 기존 장비 회수는 각각 확인한다.
- 문제 해결은 파손·분실·못 받음·수량 정정·금액 정정·접수 취소의 여섯 선택지다. 품목이 많으면 세 개씩 쪽을 나눈다. 상태·분실은 실제 물품 선택과 기존 확정을 거친다. 수량 정정은 이미 반납한 품목도 원래 처리 기록을 열 수 있다.
- Pretendard와 공용 16/18/22/24px, 최소 52px 버튼을 유지했다. 새 글꼴·글자 축소·강제 줄바꿈을 넣지 않았다. 긴 문구는 기존 `P.fitPage`를 쓴다.

| 시안 | 실제 화면·코드 | 유지한 차이와 이유 |

| P25 교환 사이즈 | 같은 파일의 `exchange`, `pos-fulfillment.js`의 교환 요청·이동 처리 | 고정된 가짜 규격 대신 실제 등록 규격과 직접 입력을 쓴다. 현재 물품 선택·부츠 등 구성품 확인을 남겼다. 교환 방법·사유는 하단에서 열어 600px 높이 안에 담는다. 요청과 실물 이동은 별도다. |

[24개 업무 검사 기록](pos-ui-a2/fulfillment-checks.json) · [교환 규격 오류 화면](pos-ui-a2/exchange-missing-size-1024x600.png). 오류가 있으면 회색 요약 자리에 경고를 보여 주며, 선택을 고치면 요약으로 돌아온다.

추가 업무 검사 다섯 가지:
1. 달력의 연장 금액 재계산·취소, 하위 입력창을 거친 뒤에도 오래된 자료로 저장하지 않음.
2. 익일 수거 타임 중복 선택과 날짜 복귀, 직접 입력한 장소·차량이 고른 품목에만 적용됨.
3. 여러 쪽의 대상 품목에서 분실 선택 후 실제 물품 확정 전까지 쓰기 없음, 다른 물품 상태 유지.
4. 반납 완료 품목의 원래 기록으로 수량 정정, 금액·접수 취소는 접수 전체 절차로 이동.
5. 실제 재고 규격·현재 사이즈 선택 제한, 파손의 동일 규격 허용, 구성품 규격 확인과 차량 교환 요청 뒤에도 실물 지급·회수는 미처리 상태.

```bash
npm run build
npm run dev
npm run test:pos:operating
npm run test:pos:fulfillment
npm run test:pos:tickets
npm run test:pos:management
npm run test:pos:preinput
npm run test:pos:keypad
SKI_SCREENS_OUT=work/pos-ui-a2-validation/captures npm run pos:screens
SKI_DRIVER_OUT=work/pos-ui-a2-validation/captures npm run pos:screens:driver
npm run pos:screens:fulfillment
npm run pos:screens:adjustments
SKI_SCREENS_OUT=work/pos-ui-a2-validation/captures SKI_RULES_TABLE=0 node scripts/check-pos-ui-rules.cjs
npm run check
npm run test:workflows:unit
npm run test:returns
npm run test:notifications
npm run test:pwa
```

`pos:screens:adjustments`는 `work/pos-ui-a2`에 다섯 크기 × 네 화면 20장과 비교 그림 세 장을 만든다. 출력 위치는 `SKI_ADJUSTMENTS_SCREENS_OUT`으로 바꿀 수 있다. 기존 포스·기사·A1 촬영은 회귀 검사만 하고 PNG를 다시 커밋하지 않는다.
