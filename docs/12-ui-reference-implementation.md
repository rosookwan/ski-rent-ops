# 2026-09-08 UI 기준 시안 적용

사용자가 제공한 `# 스키렌탈샵 UI 개선` 폴더의 01~11 `.dc.html`을 로컬 서버에서 열어 비교했다. 각 시안의 글꼴, 색상, 여백, 카드·표·버튼 구성을 기존 체험 화면에 적용했다.

## 적용 순서와 범위

1. 공통 메뉴·글꼴: 모든 매장 메뉴를 기본 72px 아이콘 메뉴로 통일했다. 펼치면 214px이며 다른 화면으로 이동하면 다시 접힌다. 작은 화면에서는 56px 메뉴와 겹쳐 열리는 펼침 메뉴를 쓴다. 아이콘에는 메뉴 이름과 접근성 이름을 유지했다.
2. 매장 접수: 상품·수령 및 반납·견적의 3열 배치를 적용했다. 대표자는 상단 정보 버튼에서 수정하고 고객 찾기도 상단에서 연다. 1~5일 바로 선택, 날짜별 수량과 할인 계산을 유지한다. 견적 목록은 내부에서 스크롤되고 총액·저장·미리보기는 하단에 고정된다.
3. 매장 목록: 오늘 현황, 렌탈현황, 배달·수거, 거래처 장부, 하루 마감, 고객관리, 재고·정비, 설정을 시안의 카드와 표 구성으로 정리했다. 렌탈 검색 조건 초기화, 상태별 건수, 연락처 끝 네 자리, 받을 돈·줄 돈, 대여 가능 수량의 시각적 구분을 적용했다.
4. 차량: 보라색 상단, 간단 모드의 장소·고객 2열 배치, 다음 업무 2개, 상세 모드의 왼쪽 업무 목록을 적용했다. 전화·문자·완료 버튼은 72px이고 하단에 유지된다.
5. 팝업과 반응형: 배경을 유지하는 어두운 오버레이, 14px 모서리, 키보드 닫기 및 대표자 버튼으로의 초점 복귀를 확인했다. 시안이 없는 사전 입력·QR 화면에는 공통 스타일을 적용했다.

Pretendard Variable의 기존 내장 파일을 사용한다. 기본 본문은 16px, 보조 문구는 14px, 매장 제목은 27px이다. 매장 포인트 `#FE4E10`, 차량 포인트 `#5F33E1`, 바탕 `#F8F8F8`, 테두리 `#E7E7E7`을 사용한다.

## 확인 결과

실제 브라우저 조작은 Codex 브라우저 도구로 수행했다. 기존 `npm test` / `npm run test:visual` 실행 기록과 이번 검증은 별개다.

| 항목 | 결과 |
|---|---|
| 매장 11개 메뉴 × 5개 크기 | 55개 조합 확인, 문서·루트 가로 넘침 없음 |
| 데스크톱 1440×900 / 1366×1024 / 1920×1080 | 메뉴 72px, 문서 높이 고정, 접수 저장 버튼 노출 |
| 작은 화면 736×900 / 360×900 | 메뉴 56px, 내부 스크롤, 접수 상품 탭 줄바꿈 수정 |
| 매장 설정·재고·준비·마감·QR 세부 탭 | 19개 탭 전환 및 표시 확인 |
| 차량 1024×800 | 간단·상세 모드의 주요 버튼 높이 72px, 화면 안에 표시 |
| 손님 화면 390×844 / 360×900 | FAQ 열기, 사이즈 입력 단계와 카드 표시 확인 |
| 접수·대여 | 2일 60,000원 계산, 견적 팝업, 대표자 입력·Escape·초점 복귀, 리프트권 전환, 검색·상세·일부 반납 팝업 확인 |
| 설정·장부·마감 | 25,000원 요금의 3일 미리보기 75,000원, 소인 4시간권 필터 1개, 상계 후 지급액 300,000원, 현금 차이 -5,000원 확인 |
| 자동 반납 검사 | `npm run test:returns` 25개 통과 |
| 구문·빌드 | `python3 scripts/check.py` 통과, 접수·차량 HTML 내부 스크립트도 검사에 포함 |

실제 로그인, 영구 저장, 문자 발송, 결제, 기기 간 동기화와 반납 기능의 버튼 연결은 기존 체험 범위를 유지한다. UI의 샘플 상태와 실제 운영 기능의 완료 상태를 혼동하지 않도록 기존 안내를 유지했다.
