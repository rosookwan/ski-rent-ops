# 41. 힉스필드 시안 · 기사 휴대폰 화면 (2026-09-21)

태블릿이 없을 때 기사님이 **휴대폰으로** 차량 업무를 볼 수 있게, 기사 태블릿 시안(`docs/40`의 D01~D03)과 같은 디자인을 세로 화면으로 옮겼다. 요청 문구는 `design/higgsfield/driver-phone-v1/requests.json`, 결과 등록부는 `results.json`, 보기는 `index.html`이다. 시안 이미지까지이며 `design/app` 코드는 건드리지 않았다.

> 2026-09-21 보관 방식: 구현 브랜치와 `main`에는 같은 이름의 가벼운 미리보기(`.jpg`)만 둔다. 아래에 적힌 `.png` 원본은 시안 브랜치 `claude/pos-ui-improvement-q9yqku`와 힉스필드(`results.json`의 URL)에 있다(`docs/42` 12절).

## 1. 기준 크기

문서에는 기사 화면의 휴대폰 기준이 없었다(차량은 1024×600, 고객 화면만 390·360px · `docs/30` · `docs/35`). 그래서 **360×640 세로**를 기준으로 잡았다. 작은 안드로이드폰(360×800)에서 브라우저 주소창이 보일 때의 표시 영역이고, 가장 빡빡한 조건이다. 화면이 더 길면 줄 수만 늘어난다. 힉스필드 비율은 9:16(출력 1520×2688)이다.

## 4. 실제 크기 검사 (`driver-phone-v1/fit-check/` · 크레딧 0)

시안 4장을 요청서의 글자·버튼 크기 그대로(Pretendard · 제목 22 · 본문 18 · 작은 글자 16px · 버튼 52~64px) HTML로 그려 실제 폭과 높이를 픽셀로 쟀다. 긴 팀 이름(한국대학교 스키동아리 팀)과 긴 장소(무주덕유산리조트 설천하우스 앞 주차장)를 섞어 넣었다.

| 표시 영역 | 차량 운행 | 배달 처리 | 차량 보관 | 방문 결과 판 | 잘린 글자 | 캡처 |
|---|---|---|---|---|---|---|
| 360×640 | 4줄 · 여유 0px · 7건이면 2쪽 | 품목 2종까지(미수 띠가 없으면 3종) · 여유 25px | 온전 · 여유 39px | 판 높이 568px · 헤더 아래로 들어감 | 0 | `phone-360x640.png` |
| 390×740 | 4줄(긴 이름 줄이 끼면) ~ 5줄 | 품목 3종까지(미수 띠가 없으면 4종) | 온전 | 위 여유 172px | 0 | `phone-390x740.png` |
| 412×780 | 5줄 | 품목 3종까지(미수 띠가 없으면 4종) | 온전 | 위 여유 212px | 0 | `phone-412x780-items3.png` |

- **360×640에서 네 화면 모두 들어간다.** 차량 운행의 4줄은 여유가 0px라서, 주소창이 더 두꺼운 휴대폰에서는 3줄이 된다. 쪽은 높이로 계산하므로 어느 경우에도 반쯤 잘린 줄은 나오지 않는다.
- **긴 글자는 자르지 않는다.** `시간 · 팀`이 한 줄에 안 들어가면 시간을 둘째 줄(장소 앞)로 내리고, 팀 이름이나 장소가 그래도 길면 두 줄로 줄바꿈한다. 그 줄만 높이가 늘어난다(91 → 115~165px). 품목은 들어가는 종류까지만 적고 `외 N종`으로 끝낸다.
- **배달 처리의 품목**은 360×640에서 2종(미수 안내 띠가 없으면 3종), 390×740 이상에서 3~4종까지 스크롤 없이 들어간다. 그보다 많으면 **가운데 내용만 움직이고 확정 버튼은 아래에 고정**한다. 고객 휴대폰 화면에 이미 쓰는 규칙이다(`docs/14`: 필요한 경우 내용만 스크롤하며 적용 버튼은 고정).

## 5. 구현으로 넘길 것

1. 같은 기사 화면 코드가 폭에 따라 배치만 바꾸도록 한다(예: 폭 600px 미만이면 휴대폰 배치). 기능·용어·저장 동작은 태블릿과 같다.
2. 휴대폰에서 `전화`는 `tel:` 링크로 바로 걸린다(현재 기사 화면과 같다). `출발 문자`도 같은 자리에 둔다.
3. 시안의 헤더에는 매장명이 없다. 필요하면 `차량 보관` 화면이나 나가기 확인 창에 둔다.
4. 시안에 그리지 않은 것: 수거 처리(배달 처리와 같은 배치, 버튼 문구만 `실제 수거 확정`), 알림 목록, 달력. 필요하면 같은 기준 화면(D11)을 참조로 추가한다(장당 3 크레딧).
5. 검사 기준에 `차량 휴대폰 360×640 · 390×740`을 더한다(`docs/30` 검증 기준, `docs/35` 6절의 다음 개정 때).
